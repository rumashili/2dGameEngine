API リファレンス

🎮 基本構造 (ライフサイクル)

  • Engine.setInit( ( ) => { ... } )
    ゲームの実行開始時に 1回だけ 呼ばれる関数を登録するよ。変数の初期化などに使ってね。
  • Engine.setUpdate( (dt) => { ... } )
    毎フレーム（1秒間に約60回）呼ばれるループ処理だよ。dt は前回のフレームからの経過時間（秒）が入るから、移動速度を掛けると滑らかに動くよ。

🖌️ 描画・UI (Draw)

  • Engine.clear(color) : 画面全体を指定した色（例: '#000'）で塗りつぶしてクリアするよ。
  • Engine.draw(name, x, y, width, height, angle) : アップロードしたコスチュームを描画するよ。
  • Engine.drawRect(x, y, w, h, color, fill) : 四角形を描くよ。fill を false にすると枠線だけになるよ。
  • Engine.drawCircle(x, y, radius, color, fill) : 円を描くよ。
  • Engine.drawText(text, x, y, size, color) : 文字や絵文字を描画するよ。
  • Engine.drawTextBox(text, x, y, w, h, options)
    自動で改行される本格的なテキストボックス（会話ウィンドウ）を描くよ。
    options例: { fontSize: 20, fontColor: '#fff', bgColor: 'rgba(0,0,0,0.8)', borderColor: '#fff', padding: 10 }

⌨️ 入力 (Input)

  • Engine.Input.getKey('KeyName') : キーが 押されている間ずっと true を返すよ。（例: 'ArrowRight', 'Space'）
  • Engine.Input.getKeyDown('KeyName') : キーが 押された瞬間だけ true を返すよ。
  • Engine.Input.getMouse() : マウスの情報を { x, y, isDown } のオブジェクトで返すよ。
  • Engine.Input.getMouseDown() : マウスがクリックされた瞬間だけ true を返すよ。

💥 当たり判定 (Collision)

  • Engine.Math.Collision.rectRect(x1, y1, w1, h1, x2, y2, w2, h2) : 2つの四角形が重なっているか判定するよ。
  • Engine.Math.Collision.circleCircle(x1, y1, r1, x2, y2, r2) : 2つの円が重なっているか判定するよ。
  • Engine.Math.Collision.rectCircle(rx, ry, rw, rh, cx, cy, cr) : 四角形と円が重なっているか判定するよ。アクションゲームで大活躍！
  • Engine.Math.Collision.pointRect(px, py, rx, ry, rw, rh) : 点（マウスカーソルなど）が四角形の中に入っているか判定するよ。ボタンを作る時に便利！

🧮 便利ツール・数学 (Math & Util)

  • Engine.Math.random(min, max) : minからmaxまでの間のランダムな小数を返すよ。
  • Engine.Math.lerp(a, b, t) : aからbへ、tの割合(0.0〜1.0)で滑らかに変化する値を計算するよ。カメラの追従などに便利！
  • Engine.Math.clamp(val, min, max) : valをminとmaxの間に収めるよ（画面端から出ないようにする時など）。
  • Engine.Math.moveForward(x, y, angle, distance) : 今の座標から指定した角度(度数)の方向へ進んだ新しい座標 {x, y} を返すよ。
  • Engine.play(name, volume, loop) : アップロードした音声を再生するよ。
  • Engine.log(msg) : エディタ右下のコンソールにメッセージを出力するよ。
