API リファレンス (v2 座標対応)

📍 座標系と基準点 (重要！)

  • 画面の中心が X: 0, Y: 0 だよ。
    右に行くほど X がプラス、上に行くほど Y がプラス になる数学的な座標系（デカルト座標）だよ。
  • draw や drawRect で指定する座標 (x, y) は、すべて 画像の「中心」 になるよ。

🎮 基本構造 (ライフサイクル)

  • Engine.setInit( ( ) => { ... } )
    ゲームの実行開始時に 1回だけ 呼ばれる関数を登録するよ。
  • Engine.setUpdate( (dt) => { ... } )
    毎フレーム呼ばれるループ処理だよ。dt は前回のフレームからの経過時間（秒）。

🖌️ 描画・UI (Draw)

  • Engine.clear(color) : 画面全体を指定色でクリアするよ。
  • Engine.draw(name, x, y, width, height, angle) : 画像を 中心基準 で描画するよ。angleの単位は度数。
  • Engine.drawRect(x, y, w, h, color, fill) : 四角形を 中心基準 で描くよ。
  • Engine.drawCircle(x, y, radius, color, fill) : 円を描くよ。
  • Engine.drawText(text, x, y, size, color) : 文字を 中央揃え(中心基準) で描画するよ。
  • Engine.drawTextBox(text, x, y, w, h, options)
    自動改行されるテキストボックスを (x,y)を中心 として描くよ。

⌨️ 入力 (Input)

  • Engine.Input.getKey('KeyName') : キーが 押されている間ずっと true を返すよ。（例: 'ArrowRight', 'Space', 'KeyW'）
  • Engine.Input.getKeyDown('KeyName') : キーが 押された瞬間だけ true を返すよ。
  • Engine.Input.getMouse() : マウスの現在座標をワールド座標系（中心が0,0、上が+Y）の { x, y, isDown } で取得するよ。
  • Engine.Input.getMouseDown() : マウスがクリックされた瞬間だけ true を返すよ。

💥 当たり判定 (Collision)

    ※すべての x, y 引数は 中心座標 を渡してね！

  • Engine.Math.Collision.rectRect(x1, y1, w1, h1, x2, y2, w2, h2)
  • Engine.Math.Collision.circleCircle(x1, y1, r1, x2, y2, r2)
  • Engine.Math.Collision.rectCircle(rx, ry, rw, rh, cx, cy, cr)
  • Engine.Math.Collision.pointRect(px, py, rx, ry, rw, rh)

🔥 チート級・裏技API (使うな危険!? 褒め言葉)

  • Engine.drawLine(x1, y1, x2, y2, color, width) : 自由に直線を引けるよ。レーザーやワイヤーアクションに！
  • Engine.Camera.x / y / zoom : カメラの位置や拡大率。これを動かすだけで画面全体がスクロールしたりズームするよ！
  • Engine.Effect.shake(power) : ダメージを受けた時などに画面を揺らすド迫力エフェクト！
  • Engine.Math.angleBetween(x1, y1, x2, y2) : 2点間の「角度(度数)」を一発で計算。敵がプレイヤーを正確に狙う弾を作るのに必須！
  • Engine.Math.distance(x1, y1, x2, y2) : 2点間の距離を一発で計算。
  • Engine.Storage.save(key, val) / load(key, defVal) : ブラウザを閉じても消えないセーブデータを1行で実装！
  • Engine.Time.frameCount / time / deltaTime : フレーム数や経過時間を取得。
  • Engine.drawUIText(text, x, y, size, color) : カメラの移動やズームを無視して、常に画面の同じ位置に文字を描画するよ！

📞 コールバック＆メッセージ (イベント)

  • Engine.onClick( (x, y) => { ... } ) : マウスがクリックされた瞬間に呼ばれるよ。
  • Engine.onKeyDown( (key) => { ... } ) : キーが押された瞬間に呼ばれるよ。
  • Engine.onKeyUp( (key) => { ... } ) : キーが離された瞬間に呼ばれるよ。
  • Engine.sendMessage('eventName', data) : 別のスクリプトファイルへメッセージとデータを送るよ！
  • Engine.receiveMessage('eventName', (data) => { ... }) : 別のスクリプトから送られたメッセージを受け取るよ！
    • 独立スコープ化：各スクリプトファイルは完全に独立しています！複数のスクリプトで同じ変数名（let player = 0; 等）を使ってもエラーになりません。また、複数のスクリプトで Engine.setUpdate などを書いても、上書きされずに全て同時に動きます！

🧮 便利ツール・数学 (Math & Util)

  • Engine.Math.random(min, max) : minからmaxまでの間のランダムな小数を返すよ。
  • Engine.Math.lerp(a, b, t) : aからbへ、tの割合(0.0〜1.0)で滑らかに変化する値を計算するよ。
  • Engine.Math.clamp(val, min, max) : valをminとmaxの間に収めるよ。
  • Engine.Math.moveForward(x, y, angle, distance) : 今の座標から指定した角度(度数)の方向へ進んだ新しい座標 {x, y} を返すよ。
  • Engine.play(name, volume, loop) : アップロードした音声を再生するよ。※volumeは0.0~1.0
  • Engine.log(msg) : エディタ右下のコンソールにメッセージを出力するよ。
